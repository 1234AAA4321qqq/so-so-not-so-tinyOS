# so so not so tinyOS

A custom Arch Linux-based ISO. Not tiny. Not NOT tiny either.

## What's inside
- Arch Linux base
- Openbox window manager
- PCManFM file manager
- LXTerminal
- Python, Go
- Preinstalled: autoserver

## Download
Grab the ISO from [Releases](../../releases).

## Flash to USB
sudo dd if=soso-not-so-tinyos-*.iso of=/dev/sdX bs=4M status=progress oflag=sync

## Build
Push a tag like v1.0.0. The ISO builds automatically (~30-50 min).
